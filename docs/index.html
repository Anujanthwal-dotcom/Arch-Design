Architecture Connection Rules

Arch keeps system designs clean by enforcing explicit relationship boundaries.

Source Node Target Node Relationship Status
Service Module Service is injected into parent module boundary (injects) ✓ Allowed
Function Service Function implements / provides method to parent service (implements) ✓ Allowed
External Service External database, queue, or cache injected into service (injects) ✓ Allowed
External Module External infrastructure dependency injected into module (injects) ✓ Allowed
Service Service Dependency service injected into consumer service (injects) ✓ Allowed
Module Module Submodule is part of / injected into parent module boundary (submodule) ✓ Allowed
Module Service Modules encapsulate services; edges point child to parent ✕ Blocked (Violates LLD)
Service Function Edges point from child implementer to parent service ✕ Blocked (Violates LLD)

⚡ Installing the Arch Design Agent Skill

Equip any AI coding agent with the knowledge to read, understand, validate, and draw .arch diagrams.

Method A: VS Code 1-Click Install (Easiest)

VS Code Command Palette 
1. Press Ctrl+Shift+P (or Cmd+Shift+P on macOS)
2. Type and select: Arch: Install Agent Skill
3. Choose scope:
   • "Current Workspace (.agents/skills/arch-design/)" → Best for repositories and teams
   • "Global User Profile (~/.gemini/config/skills/)" → Best across all personal projects

Method B: Manual Installation (Git Clone)

Terminal 
# Copy skill package into your project
git clone https://github.com/Anujanthwal-dotcom/Arch-Design.git /tmp/arch
mkdir -p .agents/skills
cp -r /tmp/arch/templates/skills/arch-design .agents/skills/
cp /tmp/arch/templates/AGENTS.md ./

🛠 CLI Tools for Agents & Developers

Standalone Node.js scripts bundled with the skill so agents never make syntax errors or have to guess pixel math.

1. CLI Architecture Validator

Verifies JSON schema integrity, required attributes, edge definitions, and architectural separation of concerns. Exits with code 0 on success, or code 1 with actionable error descriptions.

Terminal 
node .agents/skills/arch-design/scripts/validate.js architecture.arch

# Sample output:
# ✓ Validation Passed: 'architecture.arch' is schema-compliant. Nodes: 6, Edges: 5

2. CLI Dagre Auto-Layouter

Automatically assigns non-overlapping (x, y) visual coordinates using Dagre topological graph ranking. AI agents can generate nodes with pos: { x: 0, y: 0 } and run this command to lay them out cleanly.

Terminal 
# In-place auto-layout:
node .agents/skills/arch-design/scripts/layout.js architecture.arch

# Or output to a new file:
node .agents/skills/arch-design/scripts/layout.js architecture.arch ./output.arch

User Manual • Workflow Guide

How to Use Arch Design

A step-by-step visual guide to designing software architectures and shipping with AI agents in VS Code.

01 Installation

Install from Marketplace

Search for "Arch Design" by Anuj Anthwal in the VS Code Extensions tab (Ctrl+Shift+X / Cmd+Shift+X), then click Install.

Terminal / CLI 1-Click
code --install-extension AnujAnthwal.arch-for-LLD-design
100% offline & private. No cloud accounts, sign-ups, or telemetry required.
02 Workspace

Create or Open an Architecture

Launch the visual canvas inside your project in two easy ways:

  • Command Palette: Press Ctrl+Shift+P / Cmd+Shift+P and run Arch: New Architecture File.
  • File Explorer: Create any file ending in .arch or .lld (e.g., architecture.arch) anywhere in your repo.
Arch Design opens automatically as a native custom visual editor tab.
03 Frameworks

Select Framework Architecture

In the top toolbar, click the cascading framework selector (e.g., Web › Next.js). Choose from 14 curated presets:

Next.js NestJS React SPA FastAPI Spring Boot Flutter Go Clean Rust Tokio

View all 14 supported framework presets with logos →

The toolbar dynamically adapts with archetypes specific to your chosen stack.
04 Canvas

Add & Detail Architecture Cards

Click buttons in the top strip to drop cards onto the infinite canvas:

  • Archetypes: + Module, + Service, + Function, + External, or framework-specific components.
  • Card Details: Click inputs on cards to specify parameters (e.g. userId: string), return types, tech stack tags, and implementation file paths.
Cards auto-save your edits continuously to disk without manual save prompts.
05 Wiring

Connect Dependencies with Handles

Link caller and target components together using circular connector handles:

Caller / Consumer ● Right Handle
────────➔
● Left Handle Dependency / Target

Drag from the right handle of the calling component and release onto the left handle of the dependency. Validation prevents illegal cyclic or cross-boundary connections.

06 Layout & AI

Auto-Layout, Focus & AI Shipping

Organize complex diagrams and export them directly to AI coding assistants:

  • Auto Layout: Click Auto Layout in the top toolbar to neatly arrange cards into clean Dagre hierarchical columns.
  • Focus Mode: Turn on Focus Mode (or hover any card) to highlight connected execution paths and dim background clutter.
  • AI Coding Agents: Run Ctrl+Shift+P → Arch: Install Agent Skill, then prompt Antigravity, Cursor, or Claude: "Implement src/ according to architecture.arch".
